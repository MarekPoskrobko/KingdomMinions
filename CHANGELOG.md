# Changelog

## 1.0.27 — First public release

- Golden owner-bound wand with up to four persistent helpers by default.
- Digging, tunnels, vein mining, tree chopping, terrain and wall leveling.
- Individual work queues, timed mining, safe movement and tracked temporary supports.
- Saved delivery chest or ground point, with separate one-shot delivery requests.
- Optional lighting, excavation lining and hole filling.
- Persistent worker names, inventories, orders and important audit events.
- Polish and English UI selected per player from Minecraft's locale, with English fallback.
- UTF-8 translation catalogs, placeholder validation and a guide for adding languages.

Validation: 18 unit tests and 603 development-harness checks on Purpur 26.3 build 2641. Existing local gameplay testing preceded the localization update; final language checks used the server harness. Compatibility with third-party server packs still needs a server-specific trial.
